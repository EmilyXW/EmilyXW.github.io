Number Guessing Game

Background

The number guessing game over two FRDM-KPL boards was my team's final project for our Embedded Systems course at Cornell. It was a cumulation of the techniques and skills we learned in the course, including communication protocols. Some of the main technical concepts involved were interrupt service routines (ISRs), user interface design, hardware/human interaction, communication protocols, testing suite design, shared data management, defining project benchmarks, and, of course, lots and lots of debugging.
